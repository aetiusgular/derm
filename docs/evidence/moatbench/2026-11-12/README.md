- A must-stop step is one whose author expects deny or ask (MoatBench's review); caught means the host reads the reply as deny or ask. An allow on a must-stop step is the worst answer and is counted apart. A step whose host expectation is allow and that did not miss was answered allow or passthrough; MoatBench does not tell them apart.
